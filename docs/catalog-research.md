# Candidate catalog research: 1990–2015

Reviewed November 10, 2026. This is a 100-entry draft for the five currently supported launch adapters, with 20 entries per genre. It is a popularity-informed shortlist, not an asserted worldwide sales ranking. Regional release dates, local-player modes, exact editions, peripheral fit and game compatibility remain subject to review. Display order is not a rank. Year refers to the selected platform release, rather than necessarily the original arcade debut.

The initial catalog favors supported console editions of arcade and console franchises. Additional arcade/SNES/Mega Drive adapters are needed before expanding to many prominent early-1990s titles. God of War Collection is an alternate PS3 compilation of two PS2 candidates, retained for the existing local import; it is a distinct edition, not two additional unique games. No Switch platform release fits the 1990–2015 window.

Research starting points: [Gran Turismo / Top Gear racing list](https://www.gran-turismo.com/gb/news/00_8342103.html), [racing selections](https://www.digitaltrends.com/gaming/best-racing-games/), [PlayStation Gran Turismo timeline](https://www.playstation.com/en-us/gran-turismo/), [Game Informer fighting list](https://gameinformer.com/2019/04/25/the-30-greatest-fighting-games-of-all-time), [Metacritic action-adventure](https://www.metacritic.com/browse/game/all/action-adventure/), [3D platformers](https://www.metacritic.com/browse/game/all/3d-platformer/), [platformer history](https://gameranx.com/features/id/139851/article/every-3d-platformer-ever-made/), [hack-and-slash selections](https://www.dualshockers.com/best-hack-and-slash-video-games/), and [genre index](https://www.truetrophies.com/genre/Hack-and-Slash). These support discovery, not every metadata field or a certified top-20 ranking. Version-specific playability must be checked against official compatibility documentation and an actual cabinet test.

The user-provided [r/ROMs index](https://r-roms.github.io/), [PS2 index](https://r-roms.github.io/Sony/sony-playstation-2), [PS3 index](https://r-roms.github.io/Sony/sony-playstation-3), and [GameCube index](https://r-roms.github.io/Nintendo/nintendo-gamecube) were inspected as research references. They organize collections and formats; no distribution authorization or usable per-title SHA-256 was established. [Snahp](https://fora.snahp.eu/) could not be inspected: the web tool could not open it and Computer Use blocked Firefox access. Both sites are recorded separately from installable artifact sources. No authenticated contents, cookies, passwords or game payloads were ingested.

“Local source found” means a supported file was matched and hashed, not that its rights, exact edition or gameplay compatibility was certified. PS3 entries reference complete local folders through EBOOT.BIN; only that boot file is hashed. All other candidates still need authorized acquisition or user imports. Local sources can change after this report.

## Public archive metadata collected

The r/ROMs PS2 index led to public Internet Archive collection metadata. We collected 51 USA-edition observations covering 40 candidates: 6 Racing, 7 Fighting, 6 Action Adventure, 9 Platform and 12 Hack and Slash. The reproducible reviewed input is `catalog/pilot-public-file-metadata.json`; the administrator publishes it with `ncade-pilot --action research --subject Sengoku-Admin --research-file catalog/pilot-public-file-metadata.json`. This importer currently accepts only the reviewed PS2/USA/ZIP metadata shape.

Each record contains a source/index page, filename, compressed archive byte count, publisher-reported SHA-1/MD5 and observation time. These hashes describe ZIP archives, not extracted playable images, and have not been verified against downloaded bytes. PostgreSQL stores them in `catalog.pilot_games.metadata.externalFileResearch`; they never create an artifact, authorization flag or automatic game-download URL. The catalog retains local imports as the acquisition policy. Multiple observations may represent different revisions of the same candidate.
